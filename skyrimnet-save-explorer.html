SkyrimNet Save Explorer

A Claude Code skill that turns a Skyrim playthrough running the SkyrimNet and IntelEngine AI mods into a single, self-contained HTML page — an interactive "save explorer" journal for one character's entire run, generated straight from your own save data.

View on GitHub See a live example →

How it works

From save file to field journal

The process is collaborative: Claude inspects your data, asks a few questions along the way, and builds the page entirely from what it finds — nothing is templated or made up.

01

Upload your save data

Hand over your SkyrimNet and IntelEngine databases and logs. Claude reads them read-only and reports back what it finds — your character, the timespan, what's populated.

02

Claude asks, you decide

Theme, optional sections, whether to embed screenshots — the small decisions stay yours. Every stat and label in the final page comes from your data, never a sample.

03

Get one HTML file

A single offline page, no build step, no dependencies. Double-click it and it just opens — a shareable journal of the whole playthrough.

Tab 01
