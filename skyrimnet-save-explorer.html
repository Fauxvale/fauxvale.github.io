How it works

From save file to field journal

The process is collaborative: Claude inspects your data, asks a few questions along the way, and inscribes the page entirely from what it finds — nothing is templated or invented.

I

Hand over your save

Give Claude your SkyrimNet and IntelEngine databases and logs. It reads them read-only and reports back what it finds — your character, the timespan, what's populated.

II

Claude asks, you decide

Theme, optional sections, whether to embed screenshots — the small decisions stay yours. Every stat and label in the final page comes from your data, never a sample.

III

Receive one HTML file

A single offline page, no build step, no dependencies. Double-click it and it just opens — a shareable journal of the whole playthrough.

Tab I

SkyrimNet — the lived experience

  • Event timeline of the run
  • An interactive memory "constellation"
  • Kill ledger & diary
  • OmniSight field notes

Tab II

IntelEngine — the political layer

  • Faction relations
  • Provocation chronicle
  • Off-screen gossip
  • Any ongoing war, if the save has one

Get started

Install the skill from GitHub

The Save Explorer is a Claude Code skill. Add it to your personal skills folder once, and Claude can build a journal from any playthrough you point it at.

Before you begin: you'll need Claude Code installed, a Skyrim playthrough running the SkyrimNet and IntelEngine mods, and access to that character's save databases and logs.

1

Get the skill

Clone the repository (or use the green Code → Download ZIP button on GitHub if you don't use git):

git clone https://github.com/Fauxvale/skyrimnet-save-explorer.git
2

Install it into Claude Code

Copy the skills/skyrimnet-save-explorer folder from the repo into your personal skills directory:

macOS / Linux

cp -r skyrimnet-save-explorer/skills/skyrimnet-save-explorer ~/.claude/skills/

Windows · PowerShell

Copy-Item -Recurse skyrimnet-save-explorer\skills\skyrimnet-save-explorer $env:USERPROFILE\.claude\skills\

You should end up with ~/.claude/skills/skyrimnet-save-explorer/SKILL.md.

3

Restart Claude Code

Start a fresh session so Claude discovers the new skill. It loads automatically from your skills folder — there's nothing else to configure.

4

Run it

Open Claude Code and ask it to "build me a SkyrimNet save explorer" (or invoke /skyrimnet-save-explorer). Then follow its prompts and hand over your save data one file at a time — Claude does the rest.
