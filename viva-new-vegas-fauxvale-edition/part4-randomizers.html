Fauxvale Edition

Part Four - Randomizers

This is the fun part of Fauxvale Edition: randomizers. These optional mods completely change how you play the game by shuffling up weapons, items, skill checks, etc. and generally make the game more chaotic. This is completely optional, of course, and just for shits and giggles.

!

Everything here is optional. Install any, all, or none - and because they're modular, you can install, enable, or disable them at any time. A couple of them build on the others, so if you install those, keep them in the order shown below.

How to install each one

Same flow as the earlier parts: on the mod's Nexus page, open the Files tab and click Mod Manager Download, let it arrive in MO2's Downloads pane, double-click it to install (keep the default name), then drag it under your Fauxvale Edition separator and tick its checkbox to activate. Install them top to bottom so their load order matches the list below.

  1. NVRNG

    Optional

    Fallout: New Vegas' first true randomizer mod - the foundation everything else in this part sits on top of.

    Open on Nexus ↗

  2. NV Randomizer (NVRNG) Weapon Nerf

    Optional Add-on for NVRNG

    An add-on for NVRNG that nerfs some of the overpowered weapons the randomizer can hand you, keeping the game fun rather than trivially easy.

    Install NVRNG first. This is an add-on, so place it directly below NVRNG under your Fauxvale Edition separator.
    Open on Nexus ↗

  3. Skill Check Randomizer

    Optional

    What it says on the tin.

    Open on Nexus ↗

  4. Skill Check Randomizer YUP Patch

    Optional For Skill Check Randomizer

    The YUP patch for Skill Check Randomizer. If you install Skill Check Randomizer, this patch is required for it to work correctly on VNV, since VNV includes YUP.

    Install after Skill Check Randomizer. Place this patch directly below Skill Check Randomizer under your Fauxvale Edition separator.
    Open on Nexus ↗

One last step: load order

After installing whichever of these you want, open MO2's right-hand pane (the plugins / load order list) and move every plugin added by these mods above VNV LOD Plugins.esp, if that plugin is present in your list. Leaving them below it may cause issues with LOD.

That's Fauxvale Edition - for now

Stability, quality of life, gameplay, and randomizers are all in place. You've built out Fauxvale Edition on top of Viva New Vegas. More parts may follow, but for now, boot it up and enjoy the Mojave.
